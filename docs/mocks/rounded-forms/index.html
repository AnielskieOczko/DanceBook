Rounded form language

Every single-line control becomes a pill, like the chips, avatars and assistant bar already are. Multi-line surfaces (editor, comment cards, popovers) use a softer 24px corner, because a true pill breaks once text wraps. Colours, type and spacing are the app's own tokens from input.css; only the radius tokens below are new. Hover and focus are forced on some samples so every state shows at once.

Radius tokens

Proposed replacement for the 2/4/8px scale in @theme. Names follow the existing --radius-* convention so Tailwind emits rounded-pill, rounded-field and so on.

--radius-pill 9999px default
Input, select, search, button, chip, view switcher, Trix button groups, assistant bar, go-to control. Already exists, so the common case needs no new name.
--radius-field 24px new
Textarea, Trix editor, comment cards, date popover. Same visual weight as a pill at one line, still clean at five.
--radius-card 16px was 8px
Cards, dialogs, dropdown menus, session cards.
--radius-inset 12px new
Rows inside a rounded surface (menu options) and the author-side corner of a comment card. A nested radius stays smaller than its parent.
