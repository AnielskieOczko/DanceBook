Detail page headers: back navigation and actions

One header pattern for every detail and edit page, settling two issues together: #360 (five different "back to list" styles) and #361 (actions in different places, the Figure page wrapping onto a second row). Each option is shown on the four detail pages (Figure, Note, Training, Choreography), on the Figure edit page, and at phone width.

What differs between pages today and is kept: the Note title is serif, the Figure title carries class, medal and "Wbudowana w syllabus"; Choreography has the most actions (print, build, details, duplicate, delete). Delete is destructive and not a daily action, so options A and B move it into a "more" menu; option C keeps it visible but quiet. The back label always names the list it returns to ("Figury", "Notatki", "Treningi", "Choreografie"), never "Back".

A · Back row above the title, actions on the right star Recommended

  • Back: text link with arrow, always the first row, always on the left, 44 px tall, named after the list. On edit pages it returns to the detail page.
  • Actions: to the right of the title, one filled primary action, at most one outline secondary, everything else (and Delete) in a ⋯ menu. Never a filled red button.
  • Phone: the actions drop below the title as one row: primary fills the width, ⋯ beside it. Choreography's Print moves into the menu.
  • Build: the existing pageHeader already puts the title left and a toolbar right, so it gains backHref / backLabel parameters and a menu slot, and the Figure page moves onto it.

B · Slim top bar: back on the left, actions on the right

  • Back and actions share one bar above the title, like the Note page today. The title block below is free of controls.
  • Phone: the same bar, sticky while scrolling, so Edit and Back stay reachable on a long figure or note. Labels shorten to icons where there is no room.

Trade-off: best for long pages, but the bar competes with the app's own top navigation, and a second row of chrome above every title costs height on phones.

C · Breadcrumb above, actions on the left under the title

  • Back is a breadcrumb ("Figury / Advanced Hip Twist"): the list name is the link and the current page is plain text.
  • Actions are a left-aligned row under the title, the position you described for Training: primary, then secondary, then a quiet red text-outline Delete, all visible.

Trade-off: nothing is hidden in a menu, but Choreography's five actions need a second row on a phone, and a breadcrumb is a weaker tap target than an arrow row.
