New Collection form: three directions

A collection is a saved filter over notes. You name it, give it a cover, set the rules (name contains, minimum rating, dance styles, categories) and choose who can see it. Today's form asks for styles and categories through native multi-select boxes (Ctrl+click), takes the rating as a bare number, and never shows which notes the rules will catch.

All three keep every field of today's form and use only patterns the app already has: the page header with a back row and actions on the right (#365), pill fields and a segmented control (#214), the Notes filter pills, compact note rows (#366), and settings rows from the profile page (#217). Each is shown at desktop width and at 375 px. The examples use the dev data's styles and notes.

A. One calm form

The Note and Figure editors' language applied to the collection: one column, three groups (About, Which notes, Sharing), filter pills instead of multi-selects, and a one-line count of matching notes above the save row.

Applies to whichever direction is chosen

  • Header from #365: a back row to Collections, or to the collection's name when editing; Save as the primary action on the right; Cancel as the one outline secondary. On a phone Save fills the width and Cancel goes, since the back row does the same job.
  • Pills replace the multi-selects for styles and categories, styled like the Notes filter pills. A selected pill keeps readable text on hover (#382). Choosing a category narrows the style pills to that category's styles.
  • Minimum rating becomes a segmented control: Any, 2+, 3+, 4+, 5. No more typing a number.
  • Cover image is a small thumbnail with Choose, Change and Remove, instead of the large dashed drop zone. It's optional. Formats and size limit are unchanged.
  • Copy: "Collection Name" becomes "Name", "Collection Filters" becomes "Which notes", and the public toggle says what others will see. All labels go into both message files.
  • Out of scope: the Collections list page (#383) and what a collection can filter on.
