Badge visuals

Issue #39, part of #35. How the eight badges of the #39 spec look and where they appear: the profile Badges row, the Training timeline, and one notification line. The tone follows the owner's note that not everyone likes gamification: quiet, no confetti, no exclamation marks, nothing that nags. A user who has turned gamification off (#317) sees none of it.

Wording says “Note”, never “Material”. Dates are the day a badge was earned. Names come from the spec: Streak 5/10/20 (consecutive attended sessions), Hours 50/100/250, Perfect month, Style balance.

1. The eight badges

One medallion per badge. Tiered families (Streak, Hours) use the bronze, silver and gold already in the app, one metal per tier, with the threshold number inside. One-off badges (Perfect month, Style balance) use the deep teal, never a metal. That keeps metals meaning “a tier of the same ladder”, and keeps them apart from the Bronze/Silver/Gold difficulty markers on figures, which are drawn as rising bars next to the class letter and never as a round medallion.

Locked badges stay visible as dashed rows with a plain progress line (“12 of 20 sessions”), so the next target is clear without any prompt. The list is fixed at eight, so “5 of 8 earned” is always a true fraction. Perfect month can be earned many times: it stays one row that counts them (“×2, last September”).

2. Profile Badges row

The row exists today as a placeholder (#229). Collapsed it shows the count and the latest badge. Expanded it shows earned badges first, newest first, then locked ones with progress.

3. Training timeline

The dashed slots in the timeline summary (#227) become the badges the user has earned, with the next target still shown dashed. A badge also appears once, on the session that earned it, as a small quiet line inside the expanded session. There is no animation and no banner.

4. Notification

One entry in the existing notifications list, only for the person who earned it, with the medallion in place of the generic icon. Tapping it opens the profile Badges row. No toast and no sound. Several badges earned by the same change appear as separate lines.

  • Title: the badge name. Line under it: what it was for, plain.
  • Unread dot like any other notification, cleared the same way.
  • A badge earned while the user has gamification off does not exist: nothing is evaluated (#317), so nothing is waiting when they turn it back on.

New user: nothing earned

No “you have no badges” message and no count of zero. Just the targets, as quiet as the rest of the page.

Open points for review

  • Metals and the figure medal levels. Both use bronze, silver and gold. The shapes differ (round medallion with a number, against rising bars beside a class letter) and the places differ (profile and timeline, against figure and choreography lists), but if you want zero overlap the tiers could use teal at three strengths instead. Say if you prefer that.
  • Perfect month as one counting row keeps “N of 8” honest. The alternative is one row per month earned, which grows without limit.
  • Dashed slots on the timeline show the next target. They could also be removed entirely there and kept on the profile only, which is the quietest version.
  • Artwork. One icon per family (flame, clock, calendar tick, balance), no illustrations, as the spec says.
