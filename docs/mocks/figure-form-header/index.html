Add / Edit figure: header, name and import

Issue #428. Today the top of the form stacks a "Manual Edit / Guided Edit" switch, a notice, the name field (no label), and a row where Save Figure floats between the class chip and a bare ✕. Three ways to organise it. Each is shown for Add and Edit at 375 px.

Wording, all options: the field is labelled Figure name. "Guided Edit" is an AI / JSON import, so it is renamed Import from URL or JSON (Add) and Re-import from URL or JSON (Edit); "Manual Edit" is dropped as a name because filling in the form is simply the form. Cancel is a labelled action everywhere, not only an ✕. The medal appears on Edit only (a new figure has none yet). The form sections below (Core Information, Positions & Footwork, Steps Breakdown, Connections, Videos & Resources, Figure Notes) are unchanged.

A · Name first, import tucked into an expandable row star Recommended

  • Top: the detail-headers back row ("‹ Figures" / "‹ Advanced Hip Twist"), then the title, then the labelled Figure name field and the class chip (and medal on Edit).
  • Import becomes a collapsed row "✨ Import from URL or JSON" below the name. It opens in place with the existing panel; on Add it is a normal collapsed row, on Edit it reads "Re-import".
  • Save / Cancel: a sticky bar at the bottom with Cancel (outline) and Save Figure (filled), always reachable on the long form. No ✕ at the top.
  • Cost: import is one tap further than today's always-visible switch; the people who use it most are on Add, where the row sits right under the name.

B · App-style top bar: Cancel, title, Save

  • One slim bar at the top: Cancel on the left, the page title centred, Save on the right. It stays on screen while the form scrolls. Replaces the floating Save and the bare ✕.
  • Mode switch stays visible as a two-way segmented control under the bar, with honest names: Fill in and Import on Add; Details and Re-import on Edit.
  • Cost: import stays one tap away and Save is always at the top, but the segmented control still takes a row, and the bar sits next to the app's own header.

C · Form only; import as a button that opens a sheet

  • The page is just the form: back row, title, labelled Figure name, class chip and medal. No switch and no import panel on the page.
  • Import is a quiet "✨ Import" button beside the title. It opens a bottom sheet (or full-screen on small phones) holding the URL / JSON panel, so the page stays short and the import has room.
  • Save / Cancel: sticky bottom bar, as in A.
  • Cost: the existing import panel has to be reshaped to live in a sheet, so this is the most build work; it gives the cleanest form.
